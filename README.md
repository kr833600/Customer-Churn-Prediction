Project Description

This project analyzes a Telco Customer Churn dataset using Python and Pandas.
The objective is to explore customer information and identify patterns associated with customer churn.Customer Churn Prediction Using Neural Networks

Objective

The main objective is to build a binary classification model to predict customer churn.

Dataset

The project uses the "Churn_Modelling.csv" dataset. The target column is "Exited", where 0 represents a customer who stays and 1 represents a customer who leaves.

Technologies Used

- Python
- Pandas
- Scikit-learn
- TensorFlow and Keras
- Google Colab

Methodology

1. Load and preprocess the dataset.
2. Remove unnecessary columns.
3. Convert categorical features into numerical features.
4. Split the data into training and testing sets.
5. Standardize the input features.
6. Build and train a neural network.
7. Evaluate the model using accuracy, a confusion matrix, precision, recall, and F1-score.

Results

The provided model run achieved approximately 85% test accuracy. The classification report also evaluates how well the model identifies customers who leave the bank.

Files

- "Customer_Churn_Prediction.ipynb" — Python code, model training, and evaluation.
- "Churn_Modelling.csv" — Dataset used for the prediction task.
